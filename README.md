# 🎬 MSR-AI-Clipper

**MSR-AI-Clipper** adalah aplikasi cerdas berbasis AI untuk memotong video panjang menjadi klip-klip pendek viral secara otomatis. Cocok untuk konten kreator yang ingin menghemat waktu editing!

## 🚀 Fitur Utama
* ✂️ **Auto Clipping:** Mendeteksi momen menarik dan memotongnya otomatis.
* 📝 **Auto Subtitle:** Membuat subtitle (`.srt`) secara otomatis menggunakan AI.
* ⚡ **Cepat & Ringan:** Dibuat dengan Python dan Streamlit.

## 🛠️ Cara Install (Pertama Kali)
1.  Pastikan Python sudah terinstall di komputer.
2.  Install kebutuhan sistem (dependencies):
    ```bash
    pip install -r requirements.txt
    ```

## ▶️ Cara Menjalankan
Cukup klik 2x pada file:
👉 **`Mulai_Aplikasi.bat`**

*(Atau ketik perintah ini di terminal: `streamlit run app.py`)*
